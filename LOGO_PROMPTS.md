# Fictional League — Logo Prompts

Bildgenerierungs-Prompts für die 30 fiktiven Teams. Per Team eine eigene Konzept-Zeile, oben ein gemeinsamer Style-Guide damit alle Logos visuell zusammenpassen.

**Workflow:** Style-Guide kopieren → Team-Prompt anhängen → in ChatGPT (Bilder) / DALL-E / Midjourney / Nano Banana / Imagen rein. Dann nach `public/logos/<abbrev>.png` ablegen (lowercase, z.B. `public/logos/atl.png`).

---

## Globaler Style-Guide (vor jedem Team-Prompt einsetzen)

```
Generate a professional sports team logo in modern vector style. Specifications:
- Format: square 1024x1024
- Style: bold, flat vector art, clean geometric lines, suitable for small icon use
- Composition: centered single mark, no text/wordmark
- Background: solid white OR transparent (PNG)
- Inspired by modern professional basketball logo design (clean, recognizable, aggressive)
- Limited color palette using the team colors specified below
- Avoid: photorealism, gradients, drop shadows, 3D effects, lens flares, busy backgrounds

Now generate this specific team:
```

---

## Filename Convention

`public/logos/<abbrev>.png` (lowercase). Beispiele: `atl.png`, `bos.png`, `gsw.png`. Quadratisch, idealerweise transparenter Hintergrund.

## Tipps zur Generierung

- **Konsistenz wichtiger als Perfektion** — alle 30 sollten visuell zusammenpassen. Generiere ein paar Test-Logos zuerst (z.B. PHI, BOS, GSW) und kalibriere den Style-Guide oben falls nötig.
- **Mehrere Varianten pro Team** — generiere 3–4 Varianten pro Team, wähle das beste.
- **Format-Cleanup** — falls dein Generator weißen Hintergrund liefert: `remove.bg` oder Photoshop für Transparenz.
- **Größenoptimierung** — final 512×512 PNG reicht. SVG wenn möglich (skalierbar).
- **Tools die gut funktionieren:**
  - **Nano Banana** (Gemini 2.5 Flash Image) — sehr stark für Vektor-Style
  - **DALL-E 3 via ChatGPT** — gute Konsistenz wenn man im selben Chat bleibt
  - **Midjourney v6** — höchste ästhetische Qualität, aber teurer
  - **Imagen 3** — sauber, gut für flat-vector
