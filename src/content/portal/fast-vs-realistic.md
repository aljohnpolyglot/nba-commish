# Fast vs Realistic Is Really About Throughput vs Texture

The game has two simulator paths, and they are meant for different moods.

## Realistic: use it when the game itself matters

Realistic is the stronger choice when you care about the shape of a single matchup.

It is built for:

- watched games
- playoff series
- rotation checking
- seeing whether your minute plan behaves the way you wanted

The feel is heavier because the game is played with a stronger sense of on-court flow, substitutions, fatigue, and live minutes.

This is the mode to use when you want to sit in the season.

## Fast: use it when the save is the star

Fast is the right tool when you want to move a universe forward.

It is better for:

- long calendar skips
- multi-season runs
- big commissioner saves
- checking how a league evolves over time

You still get the same broad season outcomes, but the path there is lighter and cheaper.

This is the mode to use when you want to build history quickly.

## What both simulators still share

No matter which one you choose, they are still working inside the same basketball world:

- same save state
- same schedule
- same league rules
- same injuries
- same team quality
- same long-term progression

The difference is not the universe. The difference is how deeply one game is played out.

## The simplest recommendation

Use **Realistic** for user-team nights, playoff basketball, and when you want the season to breathe.

Use **Fast** for long arcs, bulk simming, and when you want to see what ten years of decisions actually become.
